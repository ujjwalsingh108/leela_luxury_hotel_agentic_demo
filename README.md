# Leela Luxury Hotel Agentic Demo

This repository contains a local demo package for a Leela luxury hotel agentic AI experience. It includes a mirrored Leela website, knowledge-base content, integration notes, captured Assistents AI screens, and a small Node.js demo API for concierge-style actions.

## Contents

- `theleela_playwright_site/` - static mirrored website assets that can be served locally.
- `tools/` - Node.js utilities for serving the site/API, mirroring the website, and inspecting Assistents AI routes.
- `metadata/knowledge_base/` - curated knowledge-base files for the digital concierge and arrival intelligence agents.
- `metadata/guide/` - implementation and integration guides for the public agent experience.
- `metadata/runtime/` - local JSONL demo output generated by API actions.
- `metadata/assistents-ai/` - captured screenshots and route/API inspection artifacts.

## Requirements

- Node.js 20 or newer
- npm

Install dependencies:

```bash
npm install
```

## Run The Mirrored Site

Serve the static mirrored Leela site on port `4173`:

```bash
npm run serve:theleela
```

Open:

```text
http://localhost:4173/
```

## Run The Demo API

Serve the mirrored site and demo API together on port `4174`:

```bash
npm run serve:leela-api
```

Health check:

```text
http://localhost:4174/api/leela/health
```

Available demo endpoints:

- `POST /api/leela/chat`
- `POST /api/leela/send-brochure`
- `POST /api/leela/schedule-call`
- `POST /api/leela/enquiry`
- `POST /api/leela/booking-lead`
- `POST /api/leela/check-availability`
- `GET|POST /api/leela/wati/webhook`

By default the WhatsApp flow runs in mock mode and writes records to `metadata/runtime/`.

## Optional Environment Variables

Set these only when connecting real services:

- `PORT` - API/static server port, defaults to `4174`.
- `ACTION_SECRET` - optional bearer token required for `/api/leela/*` POST actions.
- `RESERVATION_URL` - official reservation URL returned in booking responses.
- `WHATSAPP_PROVIDER` - `mock`, `cloud`, or `wati`.
- `WHATSAPP_TOKEN`, `WHATSAPP_PHONE_NUMBER_ID` - WhatsApp Cloud API credentials.
- `WATI_API_BASE`, `WATI_API_TOKEN` - WATI integration credentials.
- `WATI_WEBHOOK_SECRET` - optional webhook verification secret.

## Refresh The Mirrored Site

The mirror script uses Playwright and writes a static snapshot to `theleela_playwright_site/`:

```bash
npm run mirror:theleela
```

## Assistents AI Inspection Tools

The inspection scripts in `tools/` capture screenshots and API/route metadata from the Assistents AI workspace. They expect credentials through environment variables:

```bash
ASSISTENTS_EMAIL="..." ASSISTENTS_PASSWORD="..." node tools/query-assistents-api.mjs
```

Do not commit real credentials or generated secrets.
